# 带重音的拉丁字母：看着没问题，其实印错了

**这一类语言最阴险，因为出了错你也看不出来。**

西班牙语、葡萄牙语、法语、德语、意大利语、土耳其语用的都是拉丁字母，
所以按英文做的模板看起来能用 —— 直到商品名里出现 `ñ`、`ç`、`ã`、`ü`。

问题在于**印错了还是能读**：

- `Piña`（菠萝）印成 `Pina`
- `São`（圣）印成 `Sao`
- `Größe`（尺寸）印成 `GrOSe`

阿拉伯语、泰语印错了一眼就看得出来；**这一类印错了能蒙混过验收，
一路带到正式营业**。等你发现的时候，几千个商品名已经错了。

## 一、要注意的字符比你想的多

| 语言 | 超出英文字母的部分 |
| --- | --- |
| 西班牙语 | `ñ á é í ó ú ü` 还有**倒问号 `¿` 倒感叹号 `¡`** |
| 葡萄牙语 | `ã õ â ê ô ç` |
| 法语 | `é è ê ë à â ù û î ï ô ç` |
| 德语 | `ä ö ü ß` |
| 意大利语 | `à è é ì ò ù` |
| 土耳其语 | `ç ğ ı İ ö ş ü` |
| **印尼语、马来语** | **没有特殊字符，这两个市场不用操心** |

三个要单独说的：

**西班牙语的倒问号倒感叹号**不是装饰，少了句子读起来是不完整的。
它们不在基础字符集里，通常是第一个出问题的。

**土耳其语的 i 有两个。** `i` 大写是 `İ`（带点），`ı` 大写才是 `I`。
如果小票模板里有任何"转成大写"的处理，**土耳其语商品名会变成另一个词**。
这是真错，不是难看。

**德语的 ß** 很多字库没有大写形式，通常退回成 `SS` —— 但这样**字符数变了，
列宽跟着变**，排版会歪。

## 二、打印机字符集：最常见的坑

大多数热敏打印机不认 UTF-8，要先选对字符集。

打印机**出厂默认通常是 CP437（美式英文）**，上面那些字符一个都不覆盖。
**一台没设过字符集的打印机，所有重音字符都是错的** ——
这是这类问题最常见的单一原因。

常用的字符集：西欧用 CP850 / CP858 / Windows-1252，
葡萄牙语有专门的 CP860，土耳其语用 Windows-1254。
具体编号各家不一样，要实测（`TODO: verify`）。

**欧元符号要单独注意**：CP850 里没有欧元符号。
如果你的价格是欧元，要么换一个带欧元的字符集，要么就印 `EUR`。

## 三、同一个字母可能有两种存法

`é` 在电脑里可以是一个字符，也可以是"`e` + 一个重音符号"两个字符拼起来的。
**屏幕上看完全一样，字节不一样。**

供应商给的表格、网页表单、苹果电脑传过来的文件，经常是后一种。
这种传给打印机会**把重音符号整个丢掉**，只剩下光秃秃的 `e`。

处理办法就一句话：**导入时和打印前各做一次"标准化"**（技术上叫 NFC）。
这一步能消掉一整类时有时无、查都查不出来的重音丢失问题。

选系统时可以问：**供应商给的商品资料导进来，重音符号会不会丢？**

## 四、商品名会比英文长

这类语言每个字符占一格（和中文不一样），宽度好算。
真正的问题是**词更长**：

西班牙语、葡萄牙语的商品描述比英文长大约五分之一，法语德语更长，
德语还会出现长得离谱又不能拆的复合词。

**按英文测试数据定的列宽，到实际用的时候一定会截断。**
要拿真实的当地语言商品名去试。

## 五、验收清单

**关键：用供应商给的真实资料去试，不要用手打的测试数据。**

| 序号 | 打什么 | 合格标准 |
| --- | --- | --- |
| 1 | `Piña`、`São`、`Crème`、`Größe` | 重音符号都在，没被吃掉 |
| 2 | `¿Cuánto?` `¡Gracias!` | 倒问号倒感叹号印得出来 |
| 3 | 当地货币符号 | 是符号，不是方框 |
| 4 | **从供应商表格里复制的商品名** | 和第 1 条一样正常 |
| 5 | 有大写转换的地方（土耳其语） | `i` 变成 `İ` 不是 `I` |
| 6 | 很长的德语/葡语描述 | 换行，不是从词中间截断 |
| 7 | 重打一张旧单 | 和原来一模一样 |

**第 4 条最常被跳过，也最常出问题** ——
因为只有这一条用的是"不是你自己打出来的数据"。

## 六、哪些市场用得上

**秘鲁**直接印西班牙语小票，中南美市场普遍如此。

**印尼、马来西亚不用操心** —— 它们的商业用字没有特殊符号，
打印机默认设置就能用。这一点是好消息，省一道工序。

法语在北非（摩洛哥、阿尔及利亚、突尼斯）用得多，
而且**经常和阿拉伯语印在同一张小票上** ——
那种情况的排版问题见阿拉伯语那篇，会麻烦得多。

## 七、挑系统时该问清楚的问题

1. **打印机字符集你们是怎么设的？** 是写死的还是能按国家配？
2. 用我要买的那台打印机，打一张带 `ñ`、`ç`、`ã`、`ü` 的商品名给我看。
3. 供应商给的 Excel 导进来，重音符号会不会丢？**拿我的真实文件试一遍。**
4. 商品名列宽是按英文定的还是按当地语言定的？长名字会截断还是换行？
5. 欧元符号能不能打印？（如果收欧元）
6. 小票上有没有转大写的地方？（做土耳其市场才要问）

第 2 条和第 3 条一定要当场看，口头说"支持"没用。
