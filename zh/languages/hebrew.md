# 在以色列开店：希伯来语小票会遇到什么问题

**先说结论：希伯来语比阿拉伯语好办得多，但它有一个阿拉伯语没有的坑
——整句话可能是反的。**

而且这个坑有个好处：**不懂希伯来语的人也能自己查出来。**
这篇后面会教你怎么查，一分钟就能看出小票对不对。

如果你在以色列开店，或者做的生意要给以色列客户开单，这篇值得看完。

## 一、好消息：希伯来语比阿拉伯语省事

如果你或者你的软件供应商做过中东阿拉伯语的项目，会习惯性地把一堆麻烦事
搬过来。其实**大部分都用不上**：

| 阿拉伯语要处理的 | 希伯来语 |
| --- | --- |
| 字母连笔，同一个字母在词首、词中、词尾长得不一样 | **没有这回事**，每个字母就一个样子 |
| 必须有专门的连笔引擎 | **不需要** |
| 有必须连写的字母组合，不连就是错的 | **没有** |
| 要确认是打印机连笔还是软件连笔 | **不存在这个问题** |
| 词不能从中间截断，截了字形会变 | 截断难看，但不会变成别的字 |

所以希伯来语可以**直接用打印机自带字库打**，不一定非要走图形打印。
阿拉伯语基本只能走图形打印，希伯来语不用，打印速度会快一些。

**但省下来的麻烦，换成了另一个麻烦。**

## 二、坏消息：字序可能整个是反的

希伯来语和中文、英文不一样，是**从右往左**读的。

问题出在：存文字的时候有两种存法。一种按「**读的顺序**」存
——第一个字放第一位；另一种按「**印的顺序**」存
——已经把顺序倒过来了，打印机拿到就直接从左往右印。

两种存法都是合法的，**光看文件本身分不出来是哪种**。
配错了会怎么样？整个词是反的。

关键在于：**反过来的希伯来文，看上去还是希伯来文**。
不是乱码，不是方框，就是一排正常的希伯来字母。
你不懂这门语言，看不出任何异常，当地顾客拿到手却读不通。

这就是为什么这一条必须在付钱之前验掉。

## 三、验收绝招：看词尾字母

**这个方法不用懂希伯来语，一分钟能学会。**

希伯来语有 5 个字母，放在词的**最后一位**时要换一个写法，跟在词中间时长得不一样。
这 5 对是：

| 词中间用 | 词尾用 |
| --- | --- |
| `כ` | `ך` |
| `מ` | `ם` |
| `נ` | `ן` |
| `פ` | `ף` |
| `צ` | `ץ` |

注意看右边那一列的形状特点：**`ך` `ן` `ף` 都有一条向下拖的长腿，
`ם` 是完全封口的方块，`ץ` 也带下拖的尾巴。** 记这个形状就够了。

### 怎么用

让供应商打一张样张，上面印这个词：

```
שלום
```

这是「你好」，以色列人天天用。它的**最后一个字母是 `ם`**，就是那个封口的方块。

希伯来语从右往左读，所以「最后一个字母」印出来应该在**最左边**。

- ✅ **方块 `ם` 出现在这个词的最左边** → 字序对了
- ❌ **方块 `ם` 出现在最右边** → **字序反了，整张小票都是反的**

就这么简单。不用认识任何一个字母，只要找那个封口的方块在哪一头。

同样的道理：凡是印出来的词，**带长腿或封口方块的那几个字母如果出现在词的最右边，
基本可以断定反了**。因为词尾字母按定义只能在词的末尾，而末尾在左边。

**发现反了不要接受"我们改一下顺序就行"这种回答。**
让他们说清楚是打印机端配错了还是软件端配错了，改完重新打样再验一次。
两边都改会抵消，等于没改。

## 四、还要看的几处

打样张的时候顺便看这几样：

| 看哪里 | 对的样子 |
| --- | --- |
| 词尾字母（上一节） | 封口方块 `ם` 在词的最左边 |
| 商品名带英文品牌的那一行 | 这一行整体方向和其他行一致，没有单独一行反过来 |
| 数字，比如 `2 × 3.50` | 数字本身从左往右读，小数点没有跑到数字外面去 |
| 金额 `1,234.50` | 逗号和小数点都在数字里面，没有跳到另一头 |
| 折扣 `-10%` | 减号和百分号贴着数字，没有跑到另一边 |
| 三行不同长度的商品 | 小数点上下对齐成一条竖线 |
| 谢克尔符号 `₪` | 印出来是符号，不是方框也不是空白 |
| 80mm 和 58mm 各打一张 | 两张都能看，58mm 是重新排的不是硬挤的 |
| 重打一张旧单 | 和原来那张一模一样 |

**最后一条特别重要。** 重打旧单如果和原单不一样，
说明系统把「印的顺序」存进数据库了。这是个会越积越多的问题：
存进去的数据本身是坏的，以后换系统、导数据、做报表全会出问题。
这时候要求他们改的是存储方式，不是打印效果。

## 五、谢克尔符号这件事

以色列货币是新谢克尔，符号 `₪`，国际代码 `ILS`。

这个符号有点特殊：**老一些的字符集里没有它**。
`Windows-1255` 这个字符集里有，另一个常见的 `ISO-8859-8` 里就没有。
打印机字库里有没有，是另一个问题，要单独试。

如果试下来印不出来：**让他们改成印 `ILS` 三个字母，不要留方框**。
价格那个位置出现一个黑方块，比印三个英文字母难看得多，
顾客也会怀疑单据是不是有问题。

## 六、语言怎么配

在以色列开店的华人商户，通常需要三种语言同时跑，
**这三个必须能分开设，不能是一个开关**：

| 用在哪 | 设成什么 | 谁看 |
| --- | --- | --- |
| 收银台界面 | 希伯来语（或英语） | 本地店员 |
| 后台、报表、进货单 | 中文 | 你自己 |
| 小票、给顾客的单据 | 希伯来语 | 顾客 |

**商品要能存两个名字**：一个希伯来语的印在小票上给顾客看，
一个中文的你自己在后台认。这是这份资料里反复出现的模式，
在以色列尤其必要 —— 你不可能靠认希伯来文来盘点。

另外，以色列零售的商品目录里**英文品牌名很常见**，
所以「希伯来文 + 英文混排」是天天都会遇到的情况，不是偶尔。
验收的时候一定要拿一个带英文品牌的商品名去试，
不要只用纯希伯来文的商品试 —— 那样测不出问题。

## 七、挑系统时该问清楚的问题

这几条直接拿去问供应商，答不上来的就是没做过：

1. **你们的希伯来文，打印机端是按「读的顺序」还是「印的顺序」发过去的？
   我要买的这个型号你们试过没有？**
   —— 这是第一个问题，也是最重要的。答不上来的基本没做过以色列项目。

2. **能不能先打一张样张给我，上面要有：一个希伯来文商品名、
   一个带英文品牌的商品名、三行不同长度的商品和金额、一个 `₪` 符号、
   一个 `-10%` 的折扣行？**
   —— 拿到样张按第三、四节自己验。

3. **数据库里存的是「读的顺序」吗？重打一张三个月前的单，
   能不能和原单一模一样？**
   —— 存错了以后换系统会很痛苦。

4. **收银台、后台、小票这三个语言能不能分开设？
   一个商品能不能存希伯来文名和中文名两个名字？**

5. **`₪` 印不出来的时候，能不能改成印 `ILS`？这个是配置项还是要改程序？**

6. **80mm 和 58mm 两种纸都出一张样张。**
   —— 窄纸那张最容易露馅。

7. **样张能不能找一个懂希伯来语的人看一眼？**
   —— 前面六条你自己能验个大概，但最后还是让当地人看一眼最稳妥。
   以色列本地会计、房东、未来的店员都可以。
